[CA-RCA-001] 근본 원인 분석(RCA) 절차 - 디스플레이 불량
분석 방법론: 8D (Eight Disciplines) Problem Solving

D1 - 팀 구성:
  - 공정 엔지니어, 품질 엔지니어, 장비 엔지니어, 고객 대응 담당자

D2 - 문제 정의:
  - 불량 유형, 발생 Lot, 발생 수량, 발생 시점 정확히 기록
  - 불량 좌표 또는 위치 정보 포함

D3 - 임시 봉쇄 조치:
  - 해당 Lot 출하 즉시 정지
  - 동일 장비/공정으로 생산된 인접 Lot 추가 검사
  - 고객사 재고 중 해당 Lot 제품 격리 요청

D4 - 근본 원인 규명:
  - 5-WHY 분석 실시 (최소 5단계 반복 질문)
  - 4M (Man, Machine, Material, Method) 요인 분석
  - 공정 파라미터 트렌드 데이터 분석
  - 불량 발생 전후 변경점(4M Change Point) 확인

D5 - 영구 시정 조치 선정:
  - 근본 원인 제거를 위한 공정 조건 변경 또는 장비 개선안 수립
  - 효과 예측 및 리스크 평가 포함

D6 - 시정 조치 실행 및 검증:
  - 시범 Lot 생산 후 불량률 추이 확인
  - 통계적 공정 관리(SPC) 차트로 효과 검증

D7 - 재발 방지:
  - 공정 레시피, SOP, 검사 기준서 개정
  - 장기 모니터링 계획 수립

D8 - 팀 활동 마무리:
  - 8D 보고서 작성 및 지식 DB 등록
  - 유사 공정/제품에 수평 전개

[CA-DEFECT-DEAD-PIXEL] Dead Pixel 조치 가이드
증상: 특정 픽셀이 항상 꺼져 있는 상태

즉시 조치:
1. 불량 좌표 기록 및 양부 판정 기준 대조
2. 단일 불량: 레이저 리페어 장비로 TFT 우회 배선 시도
3. 다발 불량 (10개 이상): 해당 Lot 전수 검사, 공정 이상 조사 착수

공정 원인 분석:
  - CVD 파티클 → 챔버 클리닝, 파티클 이력 조회
  - 게이트 절연막 핀홀 → 막 두께 및 품질 재측정
  - 포토 결함 → 마스크 검사, CD 이력 조회

예방 조치:
  - 인라인 AOI 감도 상향 조정
  - CVD 챔버 클리닝 주기 단축
  - 공정 간 파티클 카운터 알람 임계값 하향

[CA-DEFECT-MURA] Mura Defect 조치 가이드
증상: 화면 밝기 불균일 (얼룩, 구름 패턴)

즉시 조치:
1. 휘도 측정기(Luminance Meter)로 9-point 또는 49-point 측정
2. 패턴 형상에 따라 원인 공정 추정:
   - 수직/수평 대칭 패턴 → Cell Gap 불균일
   - 엣지 집중 패턴 → 배향막 도포 불균일
   - 불규칙 패턴 → 이물 혼입

공정 원인 분석:
  - 스페이서 높이 편차 → AFM 측정, 디스펜싱 조건 점검
  - 배향막 두께 불균일 → 막 두께 맵핑, 인쇄 속도/압력 조정
  - 합착 압력 불균일 → 프레스 장비 압력 분포 캘리브레이션

[CA-DEFECT-BURN-IN] Burn-in 조치 가이드
증상: 정지화면 노출 후 잔상 지속

즉시 조치:
1. Pixel Refresh 모드 강제 실행 (30~60분)
2. All White / All Black 전환 패턴으로 잔상 완화 시도
3. 잔상이 해소되지 않으면 유기막 열화로 영구 불량 판정

제품 설계 개선:
  - 자동 밝기 조절(ABL) 알고리즘 강화
  - 화면 이동(Pixel Shift) 기능 활성화
  - 장시간 정지화면 감지 시 자동 밝기 감소

품질 기준 강화:
  - 출하 전 Burn-in 가속 시험: 최대 밝기 24시간, 잔상 허용 기준 적용
  - OLED 유기막 재료 열화 속도 모델링 (APT 시험 결과 반영)

[CA-DEFECT-COLOR-SHIFT] Color Shift 조치 가이드
증상: 색좌표 이탈 (delta-u'v' > 0.01)

즉시 조치:
1. 색좌표 전수 측정 (9-point 이상)
2. 이탈 방향 분석: 색온도 방향 (붉음/파름) 또는 채도 방향
3. 편광판 각도 측정 → 0도 기준 ±0.3도 이내 확인

공정 원인 분석:
  - 편광판 각도 오차 → 부착 지그 재교정
  - CF 막 두께 불균일 → 포토/현상 조건 점검
  - 광학 필름 오염 → 필름 공급 롤 및 보관 환경 점검

색 보정 조치:
  - 드라이버 IC 감마 커브 재보정 (SW 조정)
  - LDIM 또는 DDEM 보정 맵 갱신
