[HISTORY-2024-Q3-001] 공정 이상 사례: CVD 챔버 파티클 급증
발생 일시: 2024년 7월 15일
영향 Lot: LOT-2407-0312 ~ LOT-2407-0318 (7 Lot)
불량 유형: Dead Pixel (군집), 건수: 총 847개 픽셀 불량
영향 수량: 패널 2,340장 중 127장 불합격 (불량률 5.4%)

원인 분석:
  - CVD 챔버 전극 수명 초과 (교체 주기 2000 Run 대비 2,450 Run 누적)
  - 전극 표면 박리 파티클이 게이트 절연막 성막 중 기판에 낙하
  - 파티클 크기: 2~8μm, TFT 게이트 전극 단락 유발

시정 조치:
  - 전극 즉시 교체 및 챔버 클리닝 실시
  - 전극 교체 주기 1500 Run으로 단축
  - 챔버 내 파티클 카운터 실시간 모니터링 추가
  - 이후 3개월간 생산 Lot 파티클 데이터 집중 모니터링

재발 여부: 조치 후 2개월 이내 재발 없음

[HISTORY-2024-Q3-002] 공정 이상 사례: 포토 마스크 오염
발생 일시: 2024년 8월 3일
영향 Lot: LOT-2408-0045 ~ LOT-2408-0052 (8 Lot)
불량 유형: Cluster Defect, 발생 위치: 패널 좌측 상단 고정 위치
영향 수량: 패널 2,880장 중 96장 불합격 (불량률 3.3%)

원인 분석:
  - 마스크 Pellicle 파손으로 이물질 마스크 면 직접 오염
  - 오염 크기: 직경 120μm 유기물 잔류물
  - 오염 위치 고정으로 인한 동일 좌표 반복 불량 패턴

시정 조치:
  - 오염 마스크 격리, 대체 마스크 즉시 투입
  - Pellicle 교체 후 마스크 세정 (SPM + DI 린스)
  - 마스크 투입 전 인라인 검사 주기 1000회 → 500회로 단축

재발 여부: 동일 마스크 오염 재발 없음, Pellicle 파손으로 인한 오염 2건 추가 발생하여 관리 기준 강화

[HISTORY-2024-Q4-001] 공정 이상 사례: ODF 액정 주입량 이탈
발생 일시: 2024년 10월 22일
영향 Lot: LOT-2410-0201 ~ LOT-2410-0209 (9 Lot)
불량 유형: Mura Defect (밝기 불균일), 경계 형태의 얼룩 패턴
영향 수량: 패널 3,240장 중 214장 불합격 (불량률 6.6%)

원인 분석:
  - ODF 디스펜서 노즐 마모로 주입량 불안정 (목표 대비 -8%)
  - 액정 주입량 부족으로 셀 갭 불균일 발생
  - 노즐 마모는 누적 분사 횟수 초과 (30만 shot 대비 41만 shot 사용)

시정 조치:
  - 노즐 즉시 교체
  - 노즐 교체 주기 25만 shot으로 단축
  - 주입량 인라인 모니터링 경보 임계값 ±3%으로 하향 조정

재발 여부: 노즐 교체 후 정상, 이후 분기별 노즐 상태 정기 점검 추가

[HISTORY-2025-Q1-001] 공정 이상 사례: IC 본딩 접촉 저항 이상
발생 일시: 2025년 1월 14일
영향 Lot: LOT-2501-0088 ~ LOT-2501-0091 (4 Lot)
불량 유형: Flicker (화면 깜박임), 일부 Stuck Pixel 동반
영향 수량: 패널 1,440장 중 38장 불합격 (불량률 2.6%)

원인 분석:
  - ACF 보관 온도 이탈 (보관 기준 4도 대비 실제 7~10도에서 72시간 노출)
  - ACF 도전 입자 접착력 저하로 본딩 저항 상승 (기준 1 Ohm 대비 최대 3.2 Ohm)
  - 냉장 보관 장비 고장이 근본 원인

시정 조치:
  - 이탈 ACF 롤 전량 폐기, 신규 ACF 투입
  - 냉장 장비 즉시 교체, IoT 온도 센서 추가 설치 (24시간 모니터링)
  - ACF 수령 시 보관 이력 확인 의무화

재발 여부: 조치 후 재발 없음, 냉장 보관 온도 모니터링 경보 시스템 구축 완료

[HISTORY-2025-Q1-002] 공정 이상 사례: 편광판 부착 각도 이탈
발생 일시: 2025년 2월 28일
영향 Lot: LOT-2502-0155 ~ LOT-2502-0162 (8 Lot)
불량 유형: Color Shift, 시야각 15도에서 delta-u'v' > 0.015
영향 수량: 패널 2,880장 중 432장 불합격 (불량률 15.0%, 주요 이상)

원인 분석:
  - 편광판 부착 지그 고정 나사 풀림으로 기준 각도 0.7도 이탈
  - 주간 캘리브레이션 점검 누락 (작업자 교대 시 인수인계 미흡)
  - 불량 발생까지 8 Lot 생산 진행 (누적 피해 확대)

시정 조치:
  - 지그 고정 나사 잠금 와셔 추가 및 토크 규격화
  - 교대 시 캘리브레이션 점검 의무화, 점검 기록 전산화
  - 인라인 각도 측정 센서 도입 검토

재발 여부: 지그 개선 후 동종 불량 없음, 인라인 각도 측정 시스템 2025년 2분기 도입 예정
