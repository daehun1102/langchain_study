[EQ-SOP-CVD-001] CVD 장비 공정 이상 대응 절차
장비 유형: PECVD (Plasma Enhanced Chemical Vapor Deposition)
적용 공정: Array 공정 - 절연막(SiNx, SiO2) 및 반도체층 증착

이상 감지 기준:
  - 챔버 내 파티클 카운트: 0.1μm 이상 10개/L 초과
  - 증착 두께 편차: 목표값 ±5% 초과
  - 가스 유량 이상: MFC 설정값 ±2% 초과

대응 절차:
1. 파티클 이상 감지 시 즉시 장비 정지, Lot 격리 조치
2. 챔버 드라이 클리닝 (NF3 플라즈마) 실행
3. 더미 기판 2매 투입 후 파티클 재측정
4. 기준치 이하 확인 후 정상 생산 재개
5. 이상 발생 전후 Lot 추가 검사 (FQC 강화)

예방 조치:
  - 주 1회 웻 클리닝 (챔버 오픈, 내벽 세정)
  - 전극 교체 주기: 500 Run당 점검, 2000 Run당 교체

[EQ-SOP-PHOTO-001] 포토 공정 마스크 관리 절차
장비 유형: 스테퍼(Stepper) / 스캐너(Scanner)
적용 공정: Array 공정 - 포토레지스트 패터닝 전 단계

이상 감지 기준:
  - 마스크 이물질: 크기 0.5μm 이상 검출 시
  - CD(Critical Dimension) 편차: 목표값 ±10% 초과
  - Overlay 오차: ±0.3μm 초과

대응 절차:
1. 인라인 마스크 검사(Mask Inspection) 결과 이상 감지 시 즉시 생산 중단
2. 마스크 세정: 황산+과산화수소(SPM) 세정 후 DI 린스
3. 세정 후 재검사, 이물 잔류 시 교체 마스크 투입
4. CD 및 Overlay 재측정, 기준 만족 후 생산 재개

마스크 수명 관리:
  - 사용 횟수 기록 (Pellicle 포함 200회마다 세정)
  - Pellicle 교체 주기: 1000회 또는 파손 즉시

[EQ-SOP-ETCH-001] 건식 에칭 장비 이상 대응 절차
장비 유형: ICP-RIE (Inductively Coupled Plasma Reactive Ion Etching)
적용 공정: Array 공정 - 금속 배선(게이트, 소스/드레인) 패터닝

이상 감지 기준:
  - 에치 레이트 편차: 목표값 ±8% 초과
  - 선폭(CD) 이상: 목표값 ±5% 초과
  - 잔류막(Residue) 감지: OES(광학 발광 분광) 신호 이상

대응 절차:
1. EPD(End Point Detection) 신호 이상 감지 시 공정 정지
2. 공정 챔버 조건 점검: RF 파워, 압력, 가스 유량
3. 더미 기판으로 조건 재확인 후 생산 재개
4. 해당 Lot 추가 CD 측정 및 단면 SEM 분석 (샘플링 강화)

[EQ-SOP-CELL-001] 액정 주입(ODF) 장비 관리 절차
장비 유형: ODF(One Drop Filling) 디스펜서
적용 공정: Cell 공정 - 액정 주입

이상 감지 기준:
  - 액정 주입량 편차: 목표값 ±0.5mg 초과
  - 디스펜싱 위치 오차: ±0.1mm 초과
  - 액정 점도 이상: 온도 25도 기준 규격값 ±10% 초과

대응 절차:
1. 주입량 이상 감지 시 디스펜서 노즐 세정 또는 교체
2. 점도 이상 시 액정 보관 온도 점검 (보관 기준: 0~5도)
3. 패턴 이상 시 위치 보정 캘리브레이션 재실행
4. 이상 발생 Lot: 셀 갭 측정(간섭계법) 전수 검사

[EQ-SOP-MODULE-001] 드라이버 IC 본딩 장비 관리 절차
장비 유형: COG(Chip on Glass) 본더
적용 공정: Module 공정 - 드라이버 IC 실장

이상 감지 기준:
  - 본딩 저항: 1 Ohm 초과
  - 본딩 위치 오차: ±10μm 초과
  - ACF 접착력: 박리 강도 0.5N/cm 미만

대응 절차:
1. 본딩 후 저항 측정 이상 시 해당 IC 재본딩 실시
2. 위치 오차 이상 시 비전 얼라인먼트 캘리브레이션 재실행
3. ACF 불량 시 롤 교체, 보관 조건(냉장 4도) 점검
4. 재본딩 후 전기 특성 검사(기능 테스트) 전수 실시
