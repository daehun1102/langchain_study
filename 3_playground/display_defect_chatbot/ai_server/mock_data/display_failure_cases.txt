[CASE-005] 픽셀 불량 유형: Line Defect (수평/수직선 불량)
발생 공정: Array 공정 - 배선 패터닝 단계
추정 원인 1: 게이트 라인 단선
  - 증상: 특정 행 전체 픽셀이 동일 색상으로 고착
  - 발생 패턴: 에칭 오버 또는 언더 에치 발생 시
  - 조치: 에치 레이트 재보정, 리페어 레이저로 단선 연결
추정 원인 2: 데이터 라인 단락
  - 증상: 수직 줄무늬, 인접 2열 이상 동시 불량
  - 발생 패턴: 포토 마스크 이물질에 의한 패턴 결함
  - 조치: 마스크 세정, 포토 공정 조건 재검토

[CASE-006] 픽셀 불량 유형: Mura Defect (밝기 불균일)
발생 공정: Cell 공정 - 액정 배향 및 스페이서 형성
추정 원인 1: 액정층 두께(Cell Gap) 불균일
  - 증상: 화면 전체 밝기 구배 (중앙 밝음, 주변 어두움 또는 그 반대)
  - 발생 패턴: 스페이서 높이 편차 발생 시
  - 조치: 스페이서 디스펜싱 조건 최적화, Gap 균일도 측정 강화
추정 원인 2: 배향막 불균일 도포
  - 증상: 특정 구역 경계가 보이는 얼룩 패턴
  - 조치: 배향막 인쇄 조건 및 러빙 방향 재점검

[CASE-007] 픽셀 불량 유형: Burn-in / Image Retention (잔상)
발생 공정: Module 공정 완료 후 - 사용 환경 요인
추정 원인 1: OLED 유기물 열화
  - 증상: 정지화면 장시간 표시 후 투명한 잔상 (고스트 이미지)
  - 발생 조건: 최대 밝기 + 단일 패턴 48시간 이상 노출
  - 조치: Pixel Refresh 알고리즘 적용, 스크린세이버 강제 활성화
추정 원인 2: 픽셀별 휘도 편차 누적
  - 증상: 장기간 사용 후 특정 영역 색좌표 이탈
  - 조치: Global Dimming 주기 조정, DDEM(Demura) 보정값 갱신

[CASE-008] 픽셀 불량 유형: Color Shift (색좌표 이탈)
발생 공정: Module 공정 - 광학 필름 적층
추정 원인 1: 편광판 각도 틀어짐
  - 증상: 특정 시야각에서 색상이 전환되거나 특정 색채 치우침
  - 측정 기준: delta-u'v' > 0.01 (sRGB D65 기준)
  - 조치: 편광판 부착 지그 재교정, 합착 각도 측정 강화
추정 원인 2: 컬러 필터 염료 불균일
  - 증상: RGB 채널 중 특정 채널의 색순도 저하
  - 발생 패턴: 컬러 필터 포토 공정 현상 과다/부족
  - 조치: 현상액 농도 및 온도 재보정

[CASE-009] 픽셀 불량 유형: Dark Spot (암점)
발생 공정: Cell 공정 - 합착(Lamination)
추정 원인 1: 이물질 혼입에 의한 국소 셀 갭 붕괴
  - 증상: 원형 또는 타원형 어두운 점, 직경 1mm 이상
  - 발생 패턴: 클린룸 환경 악화 시 빈도 급증
  - 조치: 합착 전 이물 검사(AOI) 강화, 클린룸 파티클 카운터 점검
추정 원인 2: 액정 보이드(Void) 발생
  - 증상: 점 형태 밝기 저하, 각도 변화에 따라 크기 변화
  - 조치: 액정 주입량 재보정, ODF 디스펜싱 패턴 검토

[CASE-010] 픽셀 불량 유형: Touch Defect (터치 미감지)
발생 공정: Module 공정 - 터치 센서 본딩
추정 원인 1: 터치 전극 단선 또는 저항 과다
  - 증상: 특정 영역 터치 입력 불감지 (좌표 단절)
  - 발생 패턴: ACF(이방성 도전 필름) 본딩 불량 시
  - 조치: ACF 본딩 압력/온도 프로파일 재검토, 저항 측정 강화
추정 원인 2: 터치 IC 통신 오류
  - 증상: 특정 채널 전체 불감지, 노이즈 오작동 병발
  - 조치: I2C/SPI 통신 파형 점검, 터치 IC 펌웨어 버전 확인

[CASE-011] 픽셀 불량 유형: Flicker (화면 깜박임)
발생 공정: Module 공정 - 드라이버 IC 및 FPC 본딩
추정 원인 1: 드라이버 IC VCOM 전압 불안정
  - 증상: 저주파 깜박임 (1~10Hz), 전면 또는 부분 영역
  - 발생 패턴: 온도 변화 시 악화
  - 조치: VCOM 전압 튜닝, IC 내부 레지스터 재보정
추정 원인 2: FPC(연성 회로 기판) 접촉 불량
  - 증상: 특정 신호 라인 간헐 불량, 충격에 민감
  - 조치: FPC 본딩 강도 점검, ACF 재본딩 또는 보강

[CASE-012] 픽셀 불량 유형: White Spot / Bright Dot
발생 공정: Array 공정 - TFT 소자 형성
추정 원인 1: TFT 게이트-소스 쇼트
  - 증상: 흰색 밝은 점, 전원 인가 시 항상 점등 (Hot Pixel 변형)
  - 발생 패턴: 금속 잔류물에 의한 게이트-소스 브릿징
  - 조치: 식각 공정 세정 강화, SEM 단면 분석으로 쇼트 경로 확인
추정 원인 2: 스토리지 캐패시터 불량
  - 증상: 밝기가 주기적으로 변동하는 점 불량
  - 조치: 캐패시터 용량 측정, 유전체 막 두께 재검토
